AGRILINK

AgriLink is a web platform that directly connects farmers and buyers, helping farmers get fair prices for their products while providing buyers with fresh agricultural produce.

## Features

- Farmer Registration & Login
- Buyer Registration & Login
- Product Listing
- Product Search & Filter
- Order Management
- Responsive UI

## Technology Stack

### Frontend
- React.js
- Tailwind CSS
- Vite

### Backend
- Node.js
- Express.js

### Database
- MongoDB

├── server/

## Future Enhancements

- AI Price Prediction
- Delivery Tracking
- Online Payments
- Multi-language Support
